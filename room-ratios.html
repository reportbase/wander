The room in ratios

The reader's inscribed sweep is two sweeps: left–right (the azimuth) and up–down (the altitude), both the geometry's, given before anything arrives. Each gives a ratio, so every point in view is an address: how far across against how far ahead, and how far up against how far out. From one place that is a picture, every direction and every angle, but no distance. One step, its length never measured, makes it a map: every place and size as so many steps. One counted stride writes it in metres.
