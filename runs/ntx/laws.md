# Standard formulas carrying π or e
1. **Circumference of a circle**: C = 2πr (geometry)
2. **Area of a circle**: A = πr² (geometry)
3. **Volume of a sphere**: V = (4/3)πr³ (geometry)
4. **Surface area of a sphere**: A = 4πr² (geometry)
5. **Volume of a cone**: V = (1/3)πr²h (geometry)
6. **Area of an ellipse**: A = πab (geometry; a, b semi-axes)
7. **Arc length**: s = rθ, full turn 2π rad (geometry)
8. **Area of a spherical triangle (Girard)**: A = R²(α + β + γ − π) (geometry)
9. **Pythagorean identity**: sin²θ + cos²θ = 1 (trigonometry)
10. **Angle addition (sine)**: sin(α + β) = sin α cos β + cos α sin β (trigonometry)
11. **Tangent addition**: tan(α + β) = (tan α + tan β)/(1 − tan α tan β) (trigonometry)
12. **Double angle**: cos 2θ = cos²θ − sin²θ = 1 − 2sin²θ (trigonometry)
13. **Law of cosines**: c² = a² + b² − 2ab cos C (trigonometry)
14. **Law of sines**: a/sin A = b/sin B = c/sin C = 2R (trigonometry; R circumradius)
15. **Half-angle tangent**: tan(θ/2) = sin θ/(1 + cos θ) (trigonometry)
16. **Complementary arctangents**: arctan x + arctan(1/x) = π/2 for x > 0 (trigonometry)
17. **Machin's formula**: π/4 = 4 arctan(1/5) − arctan(1/239) (analysis)
18. **Euler's formula**: e^(iθ) = cos θ + i sin θ (analysis)
19. **Euler's identity**: e^(iπ) + 1 = 0 (analysis)
20. **De Moivre's formula**: (cos θ + i sin θ)ⁿ = cos nθ + i sin nθ (analysis)
21. **Definition of e**: e = lim_(n→∞) (1 + 1/n)ⁿ (analysis)
22. **Exponential series**: eˣ = Σ_(n≥0) xⁿ/n! (analysis)
23. **Taylor series of sine**: sin x = x − x³/3! + x⁵/5! − … (analysis)
24. **Leibniz series**: π/4 = 1 − 1/3 + 1/5 − 1/7 + … (analysis)
25. **Basel problem**: Σ_(n≥1) 1/n² = π²/6 (number theory/analysis)
26. **ζ(4)**: Σ_(n≥1) 1/n⁴ = π⁴/90 (number theory/analysis)
27. **Wallis product**: π/2 = Π_(n≥1) 4n²/(4n² − 1) (analysis)
28. **Gaussian integral**: ∫_(−∞)^(∞) e^(−x²) dx = √π (analysis)
29. **Stirling's approximation**: n! ≈ √(2πn) (n/e)ⁿ (analysis)
30. **Gamma at one half**: Γ(1/2) = √π (analysis)
31. **Euler reflection formula**: Γ(z)Γ(1 − z) = π/sin(πz) (analysis)
32. **Dirichlet integral**: ∫₀^∞ (sin x)/x dx = π/2 (analysis)
33. **Integral of the Lorentzian**: ∫_(−∞)^(∞) dx/(1 + x²) = π (analysis)
34. **Cauchy integral formula**: f(a) = (1/2πi) ∮ f(z)/(z − a) dz (complex analysis)
35. **Residue theorem**: ∮ f(z) dz = 2πi Σ Res f (complex analysis)
36. **Natural logarithm as integral**: ln x = ∫₁^x dt/t (analysis)
37. **Derivative of arctangent**: d/dx arctan x = 1/(1 + x²) (analysis)
38. **Hyperbolic identity**: cosh²x − sinh²x = 1 (analysis)
39. **Hyperbolic cosine**: cosh x = (eˣ + e^(−x))/2 (analysis)
40. **Prime number theorem**: π(x) ~ x/ln x (number theory; π(x) the prime count)
41. **Coprime probability**: P(two random integers coprime) = 6/π² (number theory)
42. **Harmonic numbers**: H_n = ln n + γ + O(1/n) (number theory; γ Euler–Mascheroni)
43. **Normal density**: f(x) = (1/(σ√(2π))) exp(−(x − μ)²/(2σ²)) (probability)
44. **Standard Cauchy density**: f(x) = 1/(π(1 + x²)) (probability)
45. **Cauchy distribution function**: F(x) = ½ + (1/π) arctan((x − m)/γ) (probability)
46. **Exponential density**: f(t) = λe^(−λt) (probability)
47. **Poisson distribution**: P(k) = λᵏ e^(−λ)/k! (probability)
48. **Buffon's needle**: P(cross) = 2ℓ/(πd) (probability; needle ℓ ≤ line spacing d)
49. **Rayleigh density**: f(r) = (r/σ²) e^(−r²/(2σ²)) (probability)
50. **Normal characteristic function**: φ(t) = exp(iμt − σ²t²/2) (probability)
51. **Shannon entropy of a Gaussian**: h = ½ ln(2πeσ²) (information theory)
52. **Maxwell–Boltzmann speed distribution**: f(v) = 4π (m/(2πkT))^(3/2) v² e^(−mv²/(2kT)) (thermodynamics)
53. **Boltzmann factor**: P ∝ e^(−E/kT) (thermodynamics)
54. **Boltzmann entropy**: S = k ln W (thermodynamics)
55. **Isothermal work of an ideal gas**: W = nRT ln(V₂/V₁) (thermodynamics)
56. **Planck's radiation law**: B_ν = (2hν³/c²) · 1/(e^(hν/kT) − 1) (thermodynamics)
57. **Stefan–Boltzmann constant**: σ = 2π⁵k⁴/(15h³c²) (thermodynamics)
58. **Arrhenius equation**: k = A e^(−E_a/(RT)) (thermodynamics/chemistry)
59. **Barometric formula**: p(h) = p₀ e^(−Mgh/(RT)) (thermodynamics)
60. **Fermi–Dirac distribution**: f(E) = 1/(e^((E − μ)/kT) + 1) (statistical mechanics)
61. **Coulomb's law**: F = q₁q₂/(4πε₀r²) (electromagnetism)
62. **Field of a long straight wire**: B = μ₀I/(2πr) (electromagnetism)
63. **Biot–Savart law**: dB = (μ₀/4π) I dl × r̂/r² (electromagnetism)
64. **Capacitance of a parallel plate (Gaussian units)**: C = A/(4πd) (electromagnetism)
65. **Speed of light**: c = 1/√(μ₀ε₀) with μ₀ = 4π × 10⁻⁷ H/m (pre-2019 SI) (electromagnetism)
66. **Inverse square of a point source**: I = P/(4πr²) (optics)
67. **Malus's law**: I = I₀ cos²θ (optics)
68. **Snell's law**: n₁ sin θ₁ = n₂ sin θ₂ (optics)
69. **Brewster's angle**: tan θ_B = n₂/n₁ (optics)
70. **Double-slit intensity**: I = I₀ cos²(πd sin θ/λ) (optics)
71. **Single-slit diffraction**: I = I₀ (sin β/β)², β = πa sin θ/λ (optics)
72. **Rayleigh criterion**: sin θ = 1.22 λ/D (optics)
73. **Beer–Lambert law**: I = I₀ e^(−μx) (optics)
74. **RC charging**: V(t) = V₀(1 − e^(−t/RC)) (circuits)
75. **RL current rise**: I(t) = (V/R)(1 − e^(−Rt/L)) (circuits)
76. **LC resonance**: f₀ = 1/(2π√(LC)) (circuits)
77. **Capacitive reactance**: X_C = 1/(2πfC) (circuits)
78. **RMS of a sine wave**: V_rms = V₀/√2, mean of |sin| = 2V₀/π (circuits)
79. **Decibels**: L = 10 log₁₀(P/P₀) dB (signals)
80. **Fourier transform**: F(ω) = ∫ f(t) e^(−iωt) dt (signals)
81. **Fourier series**: f(t) = a₀/2 + Σ (aₙ cos nω₀t + bₙ sin nω₀t) (signals)
82. **Sinc function and its transform**: sinc x = sin(πx)/(πx) ↔ rect (signals)
83. **First-order low-pass cutoff**: f_c = 1/(2πRC) (signals)
84. **Shannon–Hartley capacity**: C = B log₂(1 + S/N) (signals)
85. **Simple harmonic motion**: x(t) = A cos(ωt + φ) (mechanics)
86. **Pendulum period**: T = 2π√(L/g) (mechanics)
87. **Mass–spring period**: T = 2π√(m/k) (mechanics)
88. **Kepler's third law**: T² = 4π²a³/(GM) (mechanics)
89. **Damped oscillator**: x(t) = A e^(−γt) cos(ω_d t + φ) (mechanics)
90. **Tsiolkovsky rocket equation**: Δv = v_e ln(m₀/m_f) (mechanics)
91. **Projectile range**: R = v₀² sin 2θ/g (mechanics)
92. **Capstan equation**: T_load = T_hold e^(μφ) (mechanics)
93. **Catenary**: y = a cosh(x/a) (mechanics)
94. **Radioactive decay**: N(t) = N₀ e^(−λt), t½ = ln 2/λ (nuclear physics)
95. **Reduced Planck constant**: ħ = h/(2π) (quantum)
96. **Free-particle plane wave**: ψ(x, t) = A e^(i(kx − ωt)) (quantum)
97. **Particle in a box energies**: Eₙ = n²π²ħ²/(2mL²) (quantum)
98. **Bohr radius**: a₀ = 4πε₀ħ²/(mₑe²) (quantum)
99. **Fine-structure constant**: α = e²/(4πε₀ħc) (quantum)
100. **Tunnelling probability**: T ≈ e^(−2κL), κ = √(2m(V − E))/ħ (quantum)
101. **Breit–Wigner (Lorentzian) line**: σ(E) ∝ (Γ/2)²/((E − E₀)² + (Γ/2)²) (quantum)
102. **Lorentz factor by rapidity**: γ = cosh η, βγ = sinh η, β = tanh η (relativity)
103. **Relativistic Doppler**: f′ = f √((1 + β)/(1 − β)) = f e^η (relativity)
104. **Relativistic aberration**: tan(θ′/2) = √((1 − β)/(1 + β)) tan(θ/2) (relativity)
105. **Einstein field equations**: G_μν = (8πG/c⁴) T_μν (relativity)
106. **Schwarzschild horizon area entropy**: S = kc³A/(4Għ), A = 4πr_s² (relativity)
107. **Hawking temperature**: T = ħc³/(8πGMk) (relativity)
