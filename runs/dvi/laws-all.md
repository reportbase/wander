1. **Inclination from Cartesian coordinates**: θ = arccos(z/√(x² + y² + z²)) = arccos(z/r) = { arctan(√(x² + y²)/z) if z > 0; π + arctan(√(x² + y²)/z) if z < 0; +π/2 if z = 0 and √(x² + y²) ≠ 0; undefined if x = y = z = 0 }, with r = √(x² + y² + z²) (Spherical coordinate system)

3. **Spherical to Cartesian**: x = r·sin θ·cos φ, y = r·sin θ·sin φ, z = r·cos θ (Spherical coordinate system)
4. **Cylindrical to spherical**: r = √(ρ² + z²), θ = arctan(ρ/z) = arccos(z/√(ρ² + z²)), φ = φ (Spherical coordinate system)
5. **Spherical to cylindrical**: ρ = r·sin θ, φ = φ, z = r·cos θ (Spherical coordinate system)
6. **Ellipsoidal coordinates**: x = (1/√a)·r·sin θ·cos φ, y = (1/√b)·r·sin θ·sin φ, z = (1/√c)·r·cos θ, r² = ax² + by² + cz² (Spherical coordinate system)
7. **Ellipsoidal volume element**: dV = |∂(x, y, z)/∂(r, θ, φ)|·dr dθ dφ = (1/√(abc))·r²·sin θ dr dθ dφ = (1/√(abc))·r² dr dΩ (Spherical coordinate system)
8. **Line element**: dr = dr·r̂ + r·dθ·θ̂ + r·sin θ·dφ·φ̂ (Spherical coordinate system)
9. **Spherical unit vectors**: r̂ = sin θ cos φ x̂ + sin θ sin φ ŷ + cos θ ẑ; θ̂ = cos θ cos φ x̂ + cos θ sin φ ŷ − sin θ ẑ; φ̂ = −sin φ x̂ + cos φ ŷ (Spherical coordinate system)
10. **Rotation matrix to the spherical basis**: R = [[sin θ cos φ, sin θ sin φ, cos θ], [cos θ cos φ, cos θ sin φ, −sin θ], [−sin φ, cos φ, 0]] (Spherical coordinate system)
11. **Cartesian basis from the spherical basis**: [x̂, ŷ, ẑ]ᵀ = [[sin θ cos φ, cos θ cos φ, −sin φ], [sin θ sin φ, cos θ sin φ, cos φ], [cos θ, −sin θ, 0]]·[r̂, θ̂, φ̂]ᵀ (Spherical coordinate system)
